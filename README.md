# Library Book Management System

A full-stack Library Book Management System built using the MERN stack.

## 🚀 Features

- Add new books
- View the list of books
- Store book details including:
  - Book Title
  - Author Name
  - ISBN
  - Category
  - Publication Year
- REST API for managing books
- MongoDB database integration
- React frontend
- Node.js and Express backend

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Tools
- Git
- GitHub
- Postman
